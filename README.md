# CoffeeMachineSystem

CoffeeMachineSystem — учебный проект на C# / .NET 9, моделирующий работу кофемашины и процесс приготовления напитков.

Основная идея проекта — представить рецепт напитка как последовательность связанных действий и ингредиентов. Рецепт хранится в виде дерева: действия могут содержать ингредиенты или другие действия, а при приготовлении напитка эта структура последовательно выполняется.

## Возможности

В проекте можно:

* работать с готовыми рецептами напитков;
* создавать собственные напитки;
* составлять рецепт из ингредиентов и действий;
* использовать вложенные действия внутри рецепта;
* просматривать состав и структуру рецепта;
* изменять созданные напитки;
* удалять напитки;
* запускать приготовление выбранного напитка.

В стандартное меню входят:

* эспрессо;
* американо;
* латте;
* капучино;
* раф с сиропом.

## Ингредиенты и действия

В рецептах используются разные типы ингредиентов, например:

* вода;
* молоко;
* кофе;
* сироп;
* лёд.

Над ними можно выполнять действия:

* добавить;
* перемешать;
* вскипятить;
* взбить;
* перемолоть;
* пролить.

Каждое действие проверяет, подходит ли ему полученный набор элементов, после чего возвращает результат для следующего этапа приготовления.

## Как устроен рецепт

Напиток содержит корневой элемент рецепта. Действия могут содержать другие действия и ингредиенты, поэтому из них можно строить вложенную структуру.

Например, приготовление капучино включает отдельное приготовление эспрессо, обработку молока и последующее объединение результатов.

Такой подход позволяет создавать разные рецепты из одних и тех же базовых компонентов.
